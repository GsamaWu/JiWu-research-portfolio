## 🔬 Publications

### 🥇 Weak Link Prediction in Complex Networks (ESWA 2024, JCR Q1)
- Ji Wu et al.  
- Journal: Expert Systems With Applications  
- 📄 Paper: https://doi.org/10.1016/j.eswa.2023.121234

**Summary:**  
Proposed a neural network framework for weak link prediction based on hyper latent distance in embedding space.

**My Contributions:**
- Implemented key components of the model  
- Conducted experiments on multiple real-world datasets  
- Evaluated performance using AUC and Precision  
- Performed comparisons with baseline methods

## 💻 Projects

### 🩺 Chest X-ray Disease Classification (PyTorch)
- 🔗 Project: https://github.com/GsamaWu/pytorch-chestxray-demo  

**Description:**  
Built a reproducible deep learning pipeline for medical image classification (pneumonia vs normal) using pretrained ResNet18.

**Highlights:**
- Modular PyTorch training pipeline  
- Validation-based model selection  
- Metrics: AUC & Accuracy  

**Results:**
- Validation AUC: 1.0000  
- Validation Accuracy: 0.9375  
- Test AUC: 0.9309  
- Test Accuracy: 0.8205
